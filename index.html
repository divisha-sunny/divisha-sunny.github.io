Spotify Song Analysis Dashboard

The Spotify Music Analysis Dashboard is a PowerBI visualization tool . It is crafted from original Spotify song data sourced directly from the Spotify API. This dataset encompasses song attributes, including popularity, artist information, genre classification, and various key characteristics defining each track. The dashboard unveils insights into factors affecting the popularity of the song and top music trends by genre, artist, and listening patterns. An ETL pipeline is built, which utilizes Python libraries like Pandas and Spotipy to interact with the Spotify API, retrieve data, clean it up, transform it into a usable format, and then load it into an SQLite database. Finally, it's loaded into Power BI for dashboarding to present the insights in a clear and visually appealing way.

NYC Trip Analysis Dashboard

The NYC Trip Analysis Dashboard utilizes trip records data provided by the Taxi and Limousine Commission from 2016 onwards, encompassing a staggering 615 million records. This comprehensive dashboard offers an in-depth analysis of taxi trips in New York City, revealing key insights such as the busiest pickup and drop-off locations, peak travel times, and fare variations throughout the day. By offering this information, the dashboard provides valuable insights into the city's traffic dynamics. Additionally, it conducts a thorough analysis of cab services, including Yellow taxis, Green taxis, and ride-sharing platforms such as Uber, Lyft, Juno, and Via. To achieve this, a big data pipeline was developed, leveraging Google Storage for storing raw data, Apache Spark in Databricks for data processing, Google BigQuery for storing processed data, and Looker for interactive dashboard.
